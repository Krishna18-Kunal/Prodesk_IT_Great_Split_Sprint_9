## Great Split Sprint 9.

## Development Prompts

The following prompts describe the development tasks and can be used as a record of the project workflow.

### 1. Project Setup

"Set up a Node.js project using Express.js with a clean, modular folder structure."

### 2. Server Configuration

"Create an Express server in `src/server.js`, configure middleware, and organize API routes into separate modules."

### 3. API Routes

"Implement the blog API routes according to the project requirements. Keep route handlers organized inside the `src/routes/` directory."

### 4. Middleware

"Organize reusable request-processing and error-handling middleware inside `src/middleware/`."

### 5. Validation and Error Handling

"Validate incoming request data and return appropriate HTTP status codes and clear JSON error messages."

### 6. Testing

"Test API endpoints with valid and invalid requests using Postman or another HTTP client."

### 7. Documentation

"Document project setup, dependencies, available scripts, and API usage in README.md."

### 8. Security

"Ensure secrets and environment files are excluded from Git using .gitignore. Never commit API keys or credentials."

## Note

These are development prompt templates for documenting the workflow. They are not a claim that every prompt was used verbatim. Update this file to reflect the actual implementation and requirements of the project.
