# Great Split Sprint 9

A RESTful Blog API built with Node.js and Express.js as part of the Prodesk IT Sprint 9 project.

## Tech Stack

- Node.js
- Express.js
- JavaScript
- npm

## Project Structure

```text
Prodesk_IT_Great_Split_Sprint_9/
├── src/
│   ├── middleware/
│   ├── routes/
│   └── server.js
├── .gitignore
├── package.json
├── package-lock.json
├── README.md
└── PROMPTS.md
```

## Prerequisites

- Node.js and npm installed
- Git installed (for version control)

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Krishna18-Kunal/Prodesk_IT_Great_Split_Sprint_9.git
   ```

2. Open the project directory:

   ```bash
   cd Prodesk_IT_Great_Split_Sprint_9
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

   Alternatively, run:

   ```bash
   npm start
   ```

## Available Scripts

- `npm start` – Start the server.
- `npm run dev` – Start the server with Nodemon.

## API Testing

Run the server and test the endpoints using Postman or another HTTP client. Refer to the route files in `src/routes/` and the server configuration in `src/server.js` for the actual endpoints.

## Security

- Keep environment variables and secrets out of version control.
- The `.gitignore` file excludes `node_modules/` and `.env` files.
